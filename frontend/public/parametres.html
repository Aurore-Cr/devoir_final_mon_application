🤖 Génération d'exercices par IA

Vérification du provider…

Choisis ton provider IA et ajoute la variable dans le fichier .env du serveur :

🖥️

Ollama Gratuit illimité

Local sur ton PC · Aucun compte · Fonctionne hors-ligne

Local seulement

1. Télécharger ollama.com

2. Dans un terminal : ollama pull llama3.2

3. Dans .env :

AI_PROVIDER=ollama
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2
🌐

Google Gemini Gratuit

Compte Google · 1 500 req/jour · Fonctionne partout

Cloud

1. Aller sur aistudio.google.com

2. Cliquer "Get API key" → "Create API key"

3. Dans .env :

AI_PROVIDER=gemini
GEMINI_API_KEY=AIzaSy...
🔀

OpenRouter Gratuit

Email · Modèles gratuits disponibles · Fonctionne partout

Cloud

1. Créer un compte sur openrouter.ai

2. API Keys → Create Key

3. Dans .env :

AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-...
OPENROUTER_MODEL=meta-llama/llama-3.2-3b-instruct:free
⚡

Groq Gratuit

Email · 14 400 req/jour · Très rapide

Cloud

1. Créer un compte sur console.groq.com

2. API Keys → Create API Key

3. Dans .env :

AI_PROVIDER=groq
GROQ_API_KEY=gsk_...
GROQ_MODEL=llama-3.3-70b-versatile

⚠️ Après avoir modifié .env, relancer le serveur : npm start
